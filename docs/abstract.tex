\cabstract{

随着位置服务与移动互联网的发展，下一兴趣点预测在智能出行和个性化推荐中承担了越来越具体的决策作用。与普通物品推荐不同，位置推荐不能只依据历史高频地点排序，还要判断用户在当前时间是否可能到达该地点，以及近期活动意图是否仍然连续。已有序列模型和图模型在建模转移关系时往往采用较统一的机制，同一兴趣点在早晚高峰、工作日和周末的行为差异容易被平均化，模型也更容易记住当前位置的常见去向，而较少刻画目标位置通常从哪些地点被到达。大语言模型能够利用兴趣点名称、类别和上下文语义，但经纬度被写成普通文本后，地理上相邻的位置可能被切分成差异很大的词元序列，空间连续性随之减弱。同时，兴趣点图中较稳定的高阶迁移关系难以只通过文本上下文传递给大语言模型，未在输入中直接出现但转移概率较高的候选点也容易被忽略。基于这些问题，本文研究大小模型协同学习框架，将时空结构先验、地理表示和语义推理放在同一预测目标下建模。

在小模型侧，本文构建时间增强序列动态图与双向转移建模，将轨迹按照时间槽组织为动态子图，并分别学习兴趣点的转出表示和转入表示，用于缓解只沿当前点外推造成的方向偏置。在大模型侧，本文设计地理坐标注入模块（Geographic Coordinate Injection Module, GCIM），把层级离散编码和连续频域编码结合起来，使坐标信息不再只以字符串形式进入模型，而是转化为可学习的地理表示。进一步地，本文设计兴趣点对齐模块（POI Alignment Module, PAM），将图结构表征映射到大语言模型输入侧，使高阶转移先验能够参与生成式预测。训练过程采用先对齐、后协同的两阶段策略，并通过参数高效微调控制可训练参数规模。公开签到数据及城市子集实验表明，本文方法在准确率@1、平均倒数排名等指标上均优于现有序列、图与大语言模型基线。TSPM在Gowalla上的准确率@1相对最强非本文基线提升5.49\%，GA-LLM在NYC上的准确率@1提升18.27\%。消融实验显示，时间分槽、双向转移、地理坐标注入和兴趣点对齐对应不同误差来源，框架在提高预测精度的同时仍保持较简洁的推理链路。
}

\ckeywords{下一兴趣点推荐；大小模型协同；时空建模；大语言模型；参数高效微调}

\eabstract{

Next point-of-interest (POI) prediction is a practical task in intelligent mobility and personalized recommendation, where a model has to infer not only what a user may prefer but also whether the next place is reachable in the current temporal and spatial context. Existing approaches still leave several issues unresolved. Sequential and graph-based models usually learn transitions under a relatively unified mechanism, which makes it difficult to distinguish the behavior of the same POI across different time periods. They also tend to emphasize where the current point leads to, while the incoming characteristics of the target point are less explicitly modeled. Large language models (LLMs) can use POI names, categories, and contextual descriptions, but raw geographic coordinates are tokenized as ordinary text. As a result, nearby locations may become distant token sequences, and spatial continuity is weakened. Moreover, high-order transition patterns stored in POI graphs cannot be reliably injected into the LLM semantic space through textual context alone. This thesis therefore studies a small-large collaborative learning framework that connects spatio-temporal structural priors, geographic representations, and semantic reasoning under the same next-POI prediction objective.

On the small-model branch, the proposed method builds a time-enhanced sequence-based dynamic graph and bidirectional transfer modeling. Check-in trajectories are divided into time-aware transition subgraphs, and each POI is represented from both outgoing and incoming directions to reduce one-sided path extrapolation. On the large-model branch, a Geographic Coordinate Injection Module (GCIM) combines hierarchical discrete encoding with continuous Fourier encoding, so that coordinates are injected as learnable geographic representations rather than fragile text strings. A POI Alignment Module (PAM) then maps graph-based structural representations into the LLM input space, allowing high-order transition priors to participate in generative prediction. The training procedure follows an alignment-first and collaboration-second strategy, with parameter-efficient fine-tuning used to limit the number of trainable parameters. Experiments on public check-in datasets and city-level subsets show consistent improvements over sequential, graph-based, and LLM baselines on ACC@1, MRR, and related metrics. TSPM improves ACC@1 by 5.49\% on Gowalla, and GA-LLM improves ACC@1 by 18.27\% on NYC over the strongest non-ours baselines. Ablation and diagnostic results indicate that time partitioning, bidirectional transfer, geographic injection, and POI alignment address different error sources while keeping the inference path compact.
}
