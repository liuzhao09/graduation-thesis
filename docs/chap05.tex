\section*{研究工作总结}

本文面向下一兴趣点（Next POI）预测任务，系统研究了时空结构建模与大语言模型语义推理协同的核心问题。现有方法在该任务上面临三方面根本性不足：传统序列与图模型难以刻画时段异质性与转移方向性；大语言模型对地理坐标的离散token化处理破坏了空间连续性；图结构中蕴含的高阶转移先验难以有效注入LLM语义空间。本文针对上述不足，提出了大小模型协同学习框架，将时空结构先验建模与语义推理增强统一到单一训练和推理流程中。

在具体研究内容上，本文完成了以下四项工作：

第一，对Next POI任务进行了系统的问题分析与研究空白归纳。通过综述序列模型、图模型与大语言模型三条技术路线，明确了各路线的能力边界，并提炼出”时段异质性建模不足、空间连续性缺失、转移先验注入困难”三类可解决的研究空白，为方法设计提供了直接依据。

第二，在小模型侧设计了时间增强序列动态图（TSDG）与双向转移建模机制（TSPM）。通过按时段划分转移子图，显式建模同一POI在不同时段的差异化转移规律；通过同时学习”转出”与”转入”两个方向的偏好嵌入，缓解传统单向转移建模的偏置问题。

第三，在大模型侧设计了地理坐标注入模块（GCIM）与POI对齐模块（PAM）。GCIM融合层级离散编码与连续频域编码，将地理约束以结构化方式注入语义空间，缓解坐标token化引发的空间不连续问题；PAM通过可学习映射通道将图结构转移表示与LLM语义表示对齐，使高阶转移先验在语义空间中可被读取和利用。两个模块共同构成地理感知大语言模型（GA-LLM）。

第四，构建了”先对齐、后协同”的两阶段训练策略，并基于公开签到数据集对所提方法进行了系统实验验证。实验结果表明，本文方法在Acc@1、MRR等核心指标上优于现有序列、图与大语言模型基线，其中TSPM在Gowalla数据集上Acc@1相对最强非本文基线提升5.49\%，GA-LLM在NYC数据集上Acc@1提升18.27\%。

\section*{主要创新点}

本文的主要创新点体现在以下三个方面：

\begin{enumerate}
    \item {\heiti\addCJKfontfeatures{AutoFakeBold=2}提出大小模型协同学习框架。}针对Next POI任务中结构先验与语义推理难以兼顾的问题，建立了”时空结构先验建模 + 地理语义增强 + 跨空间对齐训练”的统一方法范式，使同一框架内同时具备小模型的结构表达能力与大模型的语义泛化能力。该框架在推理阶段由GA-LLM单路输出，保证时延可控。

    \item {\heiti\addCJKfontfeatures{AutoFakeBold=2}设计时间增强序列动态图与双向转移建模。}现有方法通常以统一转移矩阵刻画POI间关系，忽略了时段差异与转移方向性。本文通过引入时间分槽动态图并同时建模转出与转入偏好，在不显著增加参数量的前提下，提升了模型对时段异质行为和复杂路径转移规律的刻画精度。

    \item {\heiti\addCJKfontfeatures{AutoFakeBold=2}提出GCIM与PAM两类大模型增强机制。}针对LLM在地理连续性和转移先验利用上的固有缺陷，GCIM通过结构化地理编码缓解坐标语义错位，PAM通过可学习跨空间映射将图结构先验注入语义表示。二者互补配合，在冷启动与跨城迁移场景中均表现出稳健的增益效果。
\end{enumerate}

\section*{研究局限与展望}

本文研究存在以下不足，有待后续工作进一步完善：

\begin{enumerate}
    \item 当前实验主要基于公开签到数据集开展离线评估，所用数据均为历史静态轨迹，对线上实时交互反馈与动态POI变化的适应能力尚未得到充分验证；
    \item 跨域泛化评估以城市级迁移为主，对跨国家、跨文化或跨业态等更强分布漂移场景的泛化能力尚待进一步考察；
    \item 天气、交通事件、节假日等外部上下文信息尚未系统纳入建模，在极端场景或突发事件条件下模型性能可能受限；
    \item 负采样策略（如困难负样本比例与采样区域设置）对最终性能的独立影响尚未系统量化，后续可开展专项消融研究。
\end{enumerate}

在上述不足的基础上，后续研究可从以下方向推进：其一，引入多模态上下文信息（地理图像、路网拓扑、实时交通信号等），增强模型在复杂城市动态环境中的语义理解能力；其二，研究在线自适应更新机制，使模型能够在新用户、新POI或概念漂移条件下持续学习；其三，进一步优化推理链路与模型压缩策略，降低端到端时延与部署成本，推进方法在工业场景中的落地应用。
