\chapter*{结论}
\addcontentsline{toc}{chapter}{结论}
\markboth{结论}{}
\label{chap:conclusion}

本文围绕下一兴趣点预测任务，讨论时空结构先验如何与大语言模型的语义推理能力协同。全文并不是将小模型和大模型简单叠加，而是从任务中反复出现的几类矛盾出发设计方法：传统序列与图模型能够刻画局部转移，却难以覆盖复杂语义和跨场景泛化；大语言模型具备较强语义理解能力，却不会天然保持经纬度连续性；兴趣点图中的高阶迁移关系对预测有价值，但如果缺少映射通道，也难以被大语言模型稳定读取。围绕这些矛盾，本文形成了结构先验建模、地理语义增强和跨空间对齐训练相结合的框架。论文首先梳理国内外研究现状，并将下一兴趣点预测中的关键困难归纳为时间异质性、空间连续性和转移先验注入三个方面；随后给出统一的问题定义、符号体系和评价口径，保证方法设计与实验比较使用同一基准。在方法层面，小模型侧构建时间增强序列动态图和双向转移建模机制，以时间分槽刻画同一兴趣点在不同时段的迁移差异，并通过转出/转入表示缓解单向路径外推带来的偏置；大模型侧设计地理坐标注入模块（Geographic Coordinate Injection Module, GCIM）和兴趣点对齐模块（POI Alignment Module, PAM），前者将层级离散编码与连续频域编码结合，后者将图结构表征映射到大语言模型语义空间，使地理约束和高阶迁移先验能够进入生成式预测过程。

实验结果表明，本文方法在公开签到数据及城市子集上取得了较稳定的改进。TSPM在Gowalla上的准确率@1相对最强非本文基线提升5.49\%，说明时间分槽和双向转移机制能够改善结构侧候选排序；GA-LLM在NYC上的准确率@1提升18.27\%，并在TKY、CA等城市/区域子集上保持正向收益，说明地理注入和兴趣点对齐对生成式路线具有可观贡献。消融与误差分析进一步显示，GCIM主要缓解坐标文本化造成的远距离偏移，PAM在目标兴趣点未显式出现、候选稀疏或语义相近的样本中提供结构补偿，TSPM则为PAM提供更稳定的时空嵌入来源。效率分析也说明，将协同关系前移到训练阶段后，推理阶段仍可保持GA-LLM单路输出，避免在线双模型联合打分带来的额外时延。由此可以看出，TSPM、GCIM和PAM并非功能重复的模块堆叠，而是分别对应结构是否可靠、空间是否一致、语义分支能否吸收结构先验三个层面；本文在实验章同时报告主结果、消融结果、空间误差、跨城迁移和效率开销，目的也在于从不同证据侧面检验这一层次关系。

本文仍存在若干限制。第一，实验主要基于公开签到数据集开展离线评估，尚未覆盖线上实时反馈、动态兴趣点变化和服务端延迟波动等因素；第二，跨域泛化评估集中在城市级迁移，对跨国家、跨文化和跨业态等更强分布漂移场景讨论不足；第三，天气、交通事件、节假日和道路拓扑等外部上下文尚未系统纳入模型，极端天气、突发活动或交通管制条件下仍可能出现可达性判断偏差；第四，不同基座模型、分词器、上下文长度、负采样策略和结构嵌入来源对PAM与GCIM的影响仍需更细粒度的对比。与此同时，离线前$K$个指标只能刻画是否命中真实下一兴趣点，尚不能完整反映多个合理替代地点在真实系统中的可接受程度，后续评价协议还需要结合地理距离、类别相似度、路线成本和用户反馈进一步细化。

后续研究可从三个方向推进。其一，引入路网拓扑、实时交通、区域功能、兴趣点图像等多模态城市上下文，使模型在复杂城市环境中获得更完整的外部证据。其二，研究在线自适应更新机制，在新用户、新兴趣点和概念漂移条件下持续修正结构与语义表示，同时控制更新成本和稳定性风险。其三，继续优化推理链路与模型压缩策略，在保证地理一致性和排序质量的前提下降低端到端时延。总体而言，本文的结论不是将大语言模型视为替代所有专门推荐模型的通用工具，而是说明在强时空约束的下一兴趣点预测中，结构先验、地理表示和语义推理需要通过可学习通道协同工作；训练期协同、表示层对齐和推理期单路输出为这一目标提供了一条可复验的实现路径。
