\chapter*{致谢}
\addcontentsline{toc}{chapter}{致谢}
\markboth{致谢}{}

三年的研究生学习即将结束。回看这段经历，我最明显的变化不是掌握了某一个模型或某一套实验流程，而是逐渐学会把一个模糊想法拆成可以验证的问题。读研初期，我花了大量时间补齐推荐系统、时空建模和大模型相关基础，很多概念在阅读论文时似乎已经理解，但真正复现代码、推导公式和分析实验时，仍会暴露出新的问题。进入课题后，围绕下一兴趣点推荐这一方向，我经历了从传统序列方法到图建模，再到大语言模型增强方案的多轮尝试。实验长期不收敛、结果波动难以解释、写作结构反复调整，这些具体困难让我认识到，研究工作需要对问题边界、方法假设和证据链条保持持续的审慎。

本文两条主线工作的形成经历了多轮讨论、验证和修正。TSPM相关研究让我更具体地理解时空行为中的结构规律与时间异质性，GA-LLM相关研究则让我看到大模型能力的边界，以及结构先验注入在实际任务中的必要性。衷心感谢导师在选题把关、方法路线、实验设计和论文写作上的持续指导。导师严谨务实的科研态度、对细节的高标准要求和对学生成长的耐心投入，使我在关键节点能够及时校正方向。导师不仅教会我如何推进一项研究，也让我理解为什么要以清晰的问题意识和可靠证据支撑研究结论。

感谢课题组各位老师和同学在数据处理、代码复核和论文讨论中的帮助。组会中的交流、对实验细节的追问以及对写作表述的讨论，都促使我不断检查自己的假设是否充分、结论是否有证据支撑。感谢学院与学校提供的学习平台与研究条件，使我能够在稳定的环境中完成课程学习、科研训练和论文写作。感谢家人和朋友在读研阶段给予的理解、支持与鼓励，他们的陪伴让我在压力较大的阶段仍能保持专注，也让我在遇到挫折时有继续调整和前进的力量。谨以此文，向所有在研究生阶段给予我指导、帮助和陪伴的人致以诚挚感谢。
