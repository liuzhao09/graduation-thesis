\chapter*{致谢}
\addcontentsline{toc}{chapter}{致谢}
\markboth{致谢}{}

三年的研究生学习即将结束，从入学时对科研只有模糊认识，到今天能够较为独立地完成问题定义、方法设计、实验验证与论文写作，这一过程远比我最初想象的更漫长，也更珍贵。读研初期，我花了大量时间补齐推荐系统、时空建模和大模型相关基础，很多看似已经理解的内容，在真正复现代码、推导公式和分析实验时又会暴露新的问题。进入课题后，围绕下一兴趣点推荐这一方向，我经历了从传统序列方法到图建模，再到大语言模型增强方案的多轮尝试。期间有过实验长期不收敛、结果波动难以解释、写作结构反复推翻重来的阶段，也正是在这些具体而琐碎的困难中，我逐渐理解研究工作的核心不是追求表面漂亮的结果，而是对问题边界、方法假设和证据链条保持诚实与清醒。

本文最终形成的两条主线工作并非一蹴而就，而是在多轮讨论、验证和修正中逐步沉淀出来的。TSPM让我更深刻地认识到时空行为中的结构规律与时间异质性，GA-LLM则让我意识到大模型能力的边界，以及结构先验注入在实际任务中的必要性。衷心感谢导师在选题把关、方法路线、实验设计和论文写作上的持续指导。导师严谨务实的科研态度、对细节的高标准要求和对学生成长的耐心投入，使我在每一个关键节点都能及时校正方向、稳步推进。导师不仅教会我怎么做研究，也让我理解了为什么要这样做研究，这份影响将长期伴随我今后的学习与工作。

感谢课题组各位老师和同学在数据处理、代码复核、论文讨论中的帮助。每一次组会交流和问题争论，都在推动我把模糊想法变成可验证命题，也让我在不断修改中学会更准确地表达问题和结论。感谢学院与学校提供的学习平台与研究条件，使我能够在相对稳定的环境中完成课程学习、科研训练和论文写作。感谢家人和朋友在读研阶段给予的理解、支持与鼓励，他们的陪伴让我能够在压力较大的阶段保持专注，也让我在面对挫折时有继续调整和前进的力量。谨以此文，向所有在研究生阶段给予我指导、帮助和陪伴的人致以最诚挚的感谢。
